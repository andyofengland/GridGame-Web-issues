# Temporal / match orchestration notes

Branch: `temporal`

This issues tracker has no runtime code. Backend Temporal work lives on the `temporal` branch of **GridGame-Web-backend**.

When filing bugs about:

- Lobby timeout / game disappeared while waiting
- Turn reminder / inactivity forfeit
- Resign / cancel not ending a remote match

…mention **Temporal** and whether you were on the local Docker stack (`temporal` UI at `http://localhost:8080`).
